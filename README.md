## 🎯 Featured Deep-Dive: COA Lecture 01

The complete lecture notes for **COA Lecture 1** are available at:
👉 **[01_COA/Lecture_01_Fetch_Cycle_Memory_Addressing.md](./01_COA/Lecture_01_Fetch_Cycle_Memory_Addressing.md)**

### Key Topics Covered in Lecture 01:
* **Fetch Cycle:** `PC → MAR → Memory → MBR/MDR → IR` and automatic PC incrementation.
* **Instruction Cycle with Interrupt:** Decision points, interrupt servicing timing, and ISR return mechanism.
* **Byte-Addressable vs. Word-Addressable Memory:** Address width calculations, word-to-byte formulas, and address space calculations.
* **PC Incrementation Numericals:** Complete step-by-step worked examples from lecture screenshots.
* **Interrupt Return Address:** GATE trap alert on returning to the **next instruction** vs. re-executing the current instruction.
* **Priority Matrix:** 5-star rating of critical GATE topics.
