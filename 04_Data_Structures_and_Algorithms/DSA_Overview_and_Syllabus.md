# Data Structures & Algorithms (DSA) — Complete GATE Syllabus & Overview

**Typical GATE Weightage:** ~14 – 18 Marks (Highest Combined Technical Weightage)

---

## 📌 Core Modules & Key High-Yield Topics

### Part I: Data Structures
* **Arrays & Matrices:** Row-major vs Column-major addressing formulas, sparse matrices.
* **Stacks:** Infix, Prefix, Postfix conversions and evaluation, Stack permutations, Parenthesis balancing.
* **Queues:** Linear queue, Circular queue capacity and pointer logic, Double-ended queue (Deque).
* **Linked Lists:** Singly, Doubly, Circular linked list operations, Cycle detection (Floyd's Tortoise and Hare).
* **Binary Trees:**
  * Tree properties: Node and height formulas, Full, Complete, Perfect binary trees.
  * Traversals: Preorder, Inorder, Postorder, Level-order.
  * Reconstruction of binary tree from traversals (Inorder + Preorder / Postorder).
* **Binary Search Trees (BST) & Balanced Trees:**
  * Insertion, Deletion, Search in BST.
  * AVL Trees: Rotations (LL, RR, LR, RL), Balance Factor, Max/Min nodes for height $h$.
  * Red-Black Trees: Properties, Black height.
* **Binary Heaps & Priority Queues:**
  * Min-heap & Max-heap properties, Array representation.
  * Heapify algorithm ($O(n)$ build heap time), Insertion and Extract-Min/Max ($O(\log n)$).
* **Hashing:**
  * Hash functions, Collision resolution techniques.
  * Separate Chaining, Open Addressing (Linear Probing, Quadratic Probing, Double Hashing).

---

### Part II: Algorithms & Analysis
* **Asymptotic Analysis & Recurrences:**
  * Big-O, Big-$\Omega$, Big-$\Theta$, Small-$o$, Small-$\omega$ notations.
  * Master Theorem (Standard & Extended cases).
  * Recursion Tree method and Substitution method.
* **Divide and Conquer:**
  * Merge Sort (Inversion count), Quick Sort (Worst-case vs Best-case recurrence, Randomized quicksort).
  * Binary Search variations.
* **Greedy Techniques:**
  * Fractional Knapsack, Activity Selection / Interval Scheduling.
  * Huffman Coding (Prefix-free codes, optimal merge patterns).
  * Minimum Spanning Trees (MST): Prim's Algorithm vs Kruskal's Algorithm (Disjoint Set Union - Find/Union by rank).
* **Dynamic Programming:**
  * 0/1 Knapsack Problem, Longest Common Subsequence (LCS), Matrix Chain Multiplication.
  * Bellman-Ford (Single source shortest path with negative edges), Floyd-Warshall (All-pairs shortest path).
* **Graph Algorithms:**
  * Breadth-First Search (BFS) and Depth-First Search (DFS): Tree edge, Back edge, Forward edge, Cross edge.
  * Topological Sorting (Directed Acyclic Graphs).
  * Dijkstra's Algorithm (Non-negative edge weights).
* **NP-Completeness Theory:**
  * Class P, NP, NP-Hard, NP-Complete.
  * Polynomial-time reductions, Classic NP-complete problems (3-SAT, Vertex Cover, Clique, Subset Sum, Hamiltonian Cycle).
